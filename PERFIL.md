# Perfil del build

**Build:** 06_Huntress_Spirit Walker_Mono_End Game [Nicro4Fun] (Guía de Novatos de Nicro4Fun, "Mono Final")
**Clase:** Huntress, ascendencia Spirit Walker (Huntress2)
**Tipo:** companions/minions (Summon Beast x2, Wild Protector, Skeletal Warrior), con evasión + deflexión y vida.

Las reglas de puntuación que salen de este perfil están en `pesos.json`.

## Qué pide la guía por slot

| Slot | Objetivo |
|---|---|
| Arma 1 | Único Tyranny's Grip con el máximo de Physical Damage (rango normal 150-200%) |
| Arma 2 | Rattling Sceptre: 28% increased Spirit, aliados 119% daño, 39% daño crítico, 16% vel. de ataque, +4 Minion Skills |
| Amuleto | +3 Minion Skills, +70 vida, +28 all Attributes, +35% resist. fuego. Anoint: Growing Swarm |
| Casco | 500+ evasión, +117 vida, +2 Minion Skills |
| Pechera | 2500+ evasión y, si se puede, alguna resistencia |
| Guantes | 500 evasión, +149 vida, 25% a cada resistencia. La guía los pide Runeforged con 20+ Runic Ward, pero ese Runic Ward lo cubren las botas |
| Botas | 30% velocidad, 500+ evasión, +149 vida, 45% frío, 45% rayo, deflexión 23% de la evasión |
| Anillos (x2) | Prismatic Ring o base con mucha resistencia: +119 vida, +10 all Attributes, +15% all res, minions 30% daño, minions 29% daño crítico (opcional) |
| Cinturón | 2+ ranuras de charm, +120 vida, +1 Minion Skills (opcional), minions 30% vida, algún atributo, Minions' Strikes have Melee Splash |
| Frascos | Vida y maná con más recuperación y menos uso de cargas |
| Charms | Anti-slow (Silver), anti-congelación (Thawing) y el único Forsaken Bangle |
| Joyas | La guía no las detalla; criterio propio: mods de minions (daño, velocidad, crítico, vida) |

## Escala de puntuación

1 = malo, 10 = idóneo (iguala lo que pide la guía para ese slot). El programa suma, por cada stat del slot, su peso por lo cerca que está del valor objetivo.
